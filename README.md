# IdlePage

A discreet VS Code novel reader with status bar reading, online book sources, and account authentication.

余页：在 VS Code 状态栏中阅读小说的自用扩展。

## Planned features

- Single-line reading in the status bar
- Keyboard navigation and quick hide/show
- Reading progress persistence
- Local TXT import
- Online book source integration
- Account login and authorization

The project is in its initial setup stage. Extension implementation has not started yet.
