# IdlePage 0.0.1 安装说明（Windows）

发布包包括 VS Code 插件 VSIX、浏览器扩展模板及许可证。适用于 Windows 桌面版 VS Code 和 Microsoft Edge；安装成品无需 Node.js。浏览器扩展版本为 0.0.11。

## 1. 安装 VS Code 插件

解压发布包。在 VS Code 的扩展页点击右上角 `…` → **从 VSIX 安装**，选择 `idle-page-0.0.1.vsix`，安装后按提示重载窗口。

只保留一个运行 IdlePage 本机服务的 VS Code 窗口，避免端口占用。测试用扩展开发窗口应先关闭。

## 2. 安装本机配对的浏览器扩展

1. 在 VS Code 命令面板运行 **IdlePage: 准备浏览器连接**。
2. 插件自动生成本机配对目录、将路径复制到剪贴板，并打开专用 Edge 扩展管理页。
3. 在这个专用 Edge 窗口开启“开发人员模式”，点击“加载解压缩的扩展”，粘贴并选择刚才复制的目录。
4. 确认名称为 **IdlePage Browser Companion**；停用旧的 **IdlePage Qidian Access Probe**。
5. 回到 VS Code，运行 **IdlePage: 重新验证接入**，需要时在专用浏览器的官方页面手动登录。

**不要直接加载发布包的 `browser-extension-template` 目录。** 它是与 VSIX 内置内容一致的无凭据模板，供分发和检查；真正安装的版本由步骤 1 在本机生成。无需手动填写 Token、Cookie 或复制浏览器登录数据。不要上传生成的配对目录或浏览器用户目录。

## 3. 阅读

悬停底部书本图标 → 进入书架 → 选择书籍 → 选择章节。

- “文本显示位置”可选择状态栏、侧栏阅读区、底部面板。
- 默认 Alt+H 统一隐藏/恢复阅读；Alt+←/→ 翻段，Alt+↓ 下一章。
- “配置快捷键”可修改所有操作的按键。
- Webview 正文区域支持滚轮翻段，正文溢出时先滚动查看，到边缘停顿后再滚动翻段。
- 正常阅读在后台运行浏览器；遇到读取失败时按提示显示浏览器检查。只读取当前账号可正常访问的内容，不执行订阅或购买。

## 4. 更新与已知限制

安装新 VSIX 并重载 VS Code 后，本机配对目录会更新。在专用 Edge 扩展管理页重新加载同一扩展目录，无需再次复制账号信息。

- 首次冷启动专用浏览器可能短暂显示窗口。
- 只获取当前页书架；不会整本自动下载，默认缓存当前章后 3 章。
- 阅读位置当前仅在本次运行中保持；正文缓存默认 200 MiB。
- 侧栏布局使用 VS Code 内置移动命令，与 Codex 的上下顺序可能因版本或已有布局不同；可拖动视图标题调整。
- 网页结构变化、账号权限或站点验证可能影响获取；失败后停止任务并提示。

SHA256SUMS.txt 用于校验包内 VSIX 和浏览器模板文件。Release 页面不需要上传任何 `.local` 目录、缓存、配对文件或个人浏览器目录。
